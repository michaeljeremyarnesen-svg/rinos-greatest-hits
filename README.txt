RINO'S GREATEST HITS — WEBAPP

Lydknapper: FAIR, SURE, NICE, MOAN, RINO LER, WHOO, SWEET, GOD DAGEN, BET, FAX, LEDDE og YOOO.

Rettelser i denne versjonen: flytende emojier vises bare under hemmelig lyd/rave, regnbuebakgrunnen er gjort større for å skjule svarte kanter under rotasjon, og logoen viser ikke lenger meldingen «Hemmelig kode startet» når koden begynner.

MP3-filer i audio/-mappen:

Hemmelig kode: trykk RINO → FAIR fem ganger → MOAN → SURE → RINO igjen, innen 10 sekunder.

GRATIS PUBLISERING MED GITHUB PAGES
1. Gå til https://github.com og logg inn/opprett gratis konto.
2. Opprett et Public repository kalt rinos-greatest-hits.
3. Velg Add file → Upload files og last opp index.html, style.css, script.js og hele audio-mappen.
4. Trykk Commit changes.
5. Gå til Settings → Pages. Under Build and deployment velger du Deploy from a branch.
6. Velg branch main og folder /(root), og trykk Save.
7. Vent litt og åpne adressen GitHub viser, vanligvis https://BRUKERNAVN.github.io/rinos-greatest-hits/

GitHub Pages er offentlig. Alle med lenken kan besøke siden, og lydfilene er også offentlig tilgjengelige. Merk: hopindibilen.mp3 er ikke inkludert fordi den ikke var blant lydfilene som ble lastet opp. Legg den i audio-mappen hvis hemmeliglyden skal kunne spilles.

Bruk bare lyd du har lov til å dele.
